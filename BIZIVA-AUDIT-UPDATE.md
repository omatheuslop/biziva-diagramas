# Atualização da auditoria — Biziva Diagramas

A base completa mantém licenças e créditos originais. A atualização contém os módulos editáveis em native-update/src/main/webapp/js/biziva e o servidor em hosting-source. Copie native-update sobre o clone completo para obter o assistente com identificação estável de solicitações. O servidor recupera o editor pelo commit público fixado em native-source.json; não expõe o backend de servlets. Configure sua própria identidade de hospedagem. Nenhuma chave ou dado de cliente está incluído.

A geração usa a carteira API do usuário, sem repetição automática após resultado incerto. Login não sincroniza arquivos. Exporte seu trabalho para backup. A revisão é limitada à integração publicada, não uma certificação de todo o código original.
